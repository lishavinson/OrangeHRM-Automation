# OrangeHRM Selenium Automation

## Project Overview

Web UI automation testing project for the OrangeHRM application using
Selenium WebDriver, Python and Pytest.

## Technologies

- Python
- Selenium WebDriver
- Pytest
- Page Object Model (POM)
- Git & GitHub

## Test Scenarios

- Valid Login
- Invalid Login
- Dashboard Verification
- Add Employee
- Search Employee
- Edit Employee
- Delete Employee
- Logout

## Project Structure

pages/
tests/
utils/
conftest.py

## How to Run

Install dependencies:

pip install -r requirements.txt

Run tests:

pytest -v

## Reporting

Pytest/Allure reports are used for test execution results.
